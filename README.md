# smart-pta-esophagus

Original code used to run the analysis and generate the figures for the paper entitled _Large scale single-cell phylogenetic mapping of clonal evolution in the human aging esophagus_

If you are looking for the Nextflow pipeline to run the variant calling analysis on your own samples, check: https://github.com/landau-lab/smartpta

SMART-PTA_SupplementaryCode.Rmd is a step-by-step pipeline linking every script to the analysis and figure it produces.
